# 🐍 Terminal Intro Card

A simple Python console application that collects a user's personal, educational, professional, interest, and project information and displays it as a clean, structured introduction card directly in the terminal.

This project was built as part of my **Python learning journey** to practice fundamental Python concepts through a small, real-world console application.

---

## 📌 Project Overview

The **Terminal Intro Card** asks the user to enter their information and then formats that information into different sections in the terminal.

Instead of being a simple "Hello World" program, this project focuses on using basic Python concepts to create a complete interactive console program.

### Information collected

* 👤 Personal Information
* 🎓 Education
* 💼 Professional Details
* 💻 Programming Language
* 🛠️ Skills
* 🎯 Career Goal
* ❤️ Personal Interests
* 🚀 Projects

## ⚙️ How to Run

### 1. Clone the repository

```bash

```

### 2. Open the project folder

```bash
cd terminal-intro-card
```

### 3. Run the program

```bash
python main.py
```

### 4. Enter your information

The program will ask questions in the terminal and generate your personal introduction card.
